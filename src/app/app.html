Classroom
La fonctionnalité Classroom de Creadoc for School permet aux enseignants d'intégrer des documents et des fiches qu'ils souhaitent partager avec leurs étudiants. Dans cette première version, les fiches interactives ne sont accessibles qu'avec un code d'authentification spécifique à chaque enseignant.
Le cahier des charges :
  • Maintenir le code "class" pour référencer le bon enseignant tout en introduisant un code personnel unique.
  • Créer deux interfaces distinctes : une pour les enseignants et une pour les étudiants.
  • Permettre la création de groupes ou de classes personnalisés avec sélection des élèves.
  • Offrir la capacité de créer différentes sections au sein de ces groupes.
  • Permettre aux enseignants de visualiser le score de chaque élève sur chaque document.
  • Pour l'interface étudiant, accès aux classes assignées et visualisation des documents.

Monify V.1
Monify est un projet né d'une problématique simple : en tant qu'auto-entrepreneur, j'ai dû effectuer des calculs complexes pour mes obligations URSSAF. Aucun outil ne répondait à mes besoins, alors j'ai créé Monify V.1 avec Gwenaël Guiraud, développeur Back-end.
Le cahier des charges :
  • Formulaire avec nom, date, montant, taux de prestation, taux d'impôt et taux de formation.
  • Interface pour visualiser les revenus par mois avec totaux.
  • Représentation graphique des totaux sur une période donnée.
  • Système de login pour la sécurité des données.
  • Menu avec gestion du mot de passe et déconnexion.
  • Application accessible en ligne.
